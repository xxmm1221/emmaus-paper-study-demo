# 圣经综合解读 · 本地资料导入

本资料为用户指定的本机既有《圣经综合解读》文字库，来源 [圣经综合解读](https://cmcbiblereading.com/)。版权归原作者所有；不是 Emmaus 原创，也不是 AI 即时生成。每章保留原文页面地址，可从阅读窗口打开。

`scripts/import-commentary.py` 从既有 66 卷 JSON 按章拆分；保留全部章节介绍、章级专题、经文引文、注释正文和原库导航索引，不改写神学内容、不补造缺失注释。共 1,189 章，30,952 条源经节记录，其中 10,538 条带注释正文。与读经使用的 31,103 节和合本是两种不同的记录粒度，不能宣称每节均有独立注释。

原库 `ref` 由旧导入程序按“优先后一条有注释的节”生成，是导航提示，不能当作本节注释的精确覆盖区间。界面对于这类跳转明确提示；没有索引时显示本章目录，不套用相邻节为本节解读。

每章 JSON 与源章对象逐字段比较相等；manifest 记录源卷文件 SHA-256、每章 SHA-256、大小及注释数量。手机按章懒加载，不一次下载整库。音频仅保留源元数据，本次未下载、重制或提供音频播放器；图片不在既有文字库内，可在原文查看。
