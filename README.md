# Emmaus · 纸间研读 Demo

手机浏览器交互原型：沉浸阅读、浮窗高度调整、上下对读、阅读历史与本地保留。

- 这里只包含可独立运行的演示页面，不是 Emmaus 应用的完整源码。
- 不连接生产后端，不包含密钥、环境配置或个人资料。
- 笔记与保留状态仅存于当前浏览器，不会同步到服务器。
- 使用 GitHub Pages 托管，无需电脑持续开机或手机连接同一 Wi-Fi。

手机触控和原生应用的最终体验仍可能有差异。

## 窗口规则

- 前台只显示一个浮窗。打开第二个时，自动保留第一个并转入后台，保留内容和阅读位置。
- 从侧栏后台恢复的页面一律全屏打开，不继承之前的小浮窗尺寸。
- 正文、浮窗和笔记各自滚动；边界手势不传到其他页面或外层网页。
- 原型最多保留六个现场、四份短笔记，满额时提示用户结束现场，不静默丢弃旧内容。
- 新建笔记（包括从经文发起）不自动分屏；只有主动点击“对读”才组合。
- 左半屏右滑打开后台；后台列表上方的“新建＋”可选书卷和章，新增独立读经浮窗。
- 目录包含 66 卷、1189 章，按书卷加载公有领域和合本经文。读经浮窗保留各自章节、浏览历史与阅读位置。

编辑源为 `src/paper-study.html`；`scripts/build-demo.py` 接收本机导出器的
`--renderer` 参数，重新生成根目录的 `index.html`。只更新这个独立 Demo 仓库，
不要上传完整 Emmaus 应用或个人资料。

经文来源与公有领域说明见 `data/README.md`。该 Demo 的静态资源读取桥只允许加载同站点的 1–66 号书卷，不访问私人服务。
