# Emmaus · 纸间研读 Demo

独立手机网页交互原型，不是完整应用，不连接生产后端。笔记和历史仅存于当前浏览器；清除浏览器数据会丢失，支持导出 JSON 本地备份。

## 当前窗口规则（2026-10-23）

- 入口原则：目录或后台“新建”的独立读经直接最大化；从经文、札记或笔记衍生的窗口默认浮窗。保留既有主场景和全局浮窗。
- 动效：右滑时后台、主阅读、浮窗和标签跟手位移与缩放；窗口形态按同一窗口身份衔接，支持减少动态效果偏好。
- 密度：缩减页头、章标题、段间和目录留白，保留正文可读性与主要按钮触控面积。
- 最大化主场景栈：单窗，或两个窗口对读；宽屏左右、窄屏上下。后台恢复置顶，不重复创建。
- 全局最多两个浮窗、三个悬浮标签；限额相互独立。切换主场景保留浮窗位置、尺寸与层级。
- 任意来源的新浮窗均叠在旧浮窗前方，不自动最大化、收起或关闭旧窗。第一个默认约40%高度；第二个错位展开，必要时适当缩短新窗以露出旧窗工具栏。已有位置的窗口恢复时保留位置。
- 上方拖柄只上下移动，下方拖柄只调整高度；正文只滚动。方向键可微调；点击后窗置顶，完全重叠时也可从窗口菜单切换到另一个浮窗。
- 两个浮窗满额时，在创建、复制、恢复标签或拆出对读之前拒绝操作。提示框可取消保持原样，或由用户明确指定“收为标签并继续”“关闭浮窗并继续”；不产生幽灵窗口、笔记或历史。
- 标签只能恢复为浮窗，不自动回收。三个标签满额时阻止新增标签；用户可以明确关闭某个标签后继续。标签有直接关闭入口；关闭仍保留内容和历史。
- 复制为浮窗（原“固定此处”）：复制独立阅读视图，原视图可继续前后翻阅；笔记视图共享内容。“转为浮窗”则移动原视图，不复制。
- 主窗移为浮窗/关闭后露出下一层；最后一层之后是书卷目录。
- 组合仅在最大化层存在，新笔记不自动分屏，不做整组浮窗。
- “拆除对读”：两窗分别最大化，上窗（宽屏左窗）在栈顶、下窗（宽屏右窗）紧随其后；旧场景与全局浮窗保留。“移出对读，转为浮窗”则只移动所选成员，剩余成员填满主阅读区；浮窗满额时整个对读保持不动。
- 只保留“最大化”，上滑收敛阅读工具不再是另一种窗口模式。
- 浮窗内滚动不穿透；外面的主窗口仍可操作。左半屏右滑打开后台。
- 历史记录可找回阅读快照、关闭窗口与笔记版本；恢复旧笔记版本不覆盖当前文本。
- 兼容v3/v4/v5/v6并迁移到v7，不沿用旧的六窗四笔记配额；浏览器容量满时提示导出，不静默删除。

目录支持66卷1189章，公有领域和合本资源按书卷加载。经文来源见 `data/README.md`。札记为罗马书8:28–29原创演示，不冒充其他经节注释。

## 开发

- 页面骨架：`src/paper-study.html`
- 视觉样式：`src/paper-study.css`
- 纯窗口状态机：`src/window-model.js`
- DOM、触控与本地保存：`src/paper-study.js`
- 构建：`python scripts/build-demo.py --renderer <本机原型导出器render.py>`
- 动效与入口浏览器回归：从 Emmaus5 根目录运行 `node artifacts/paper-study-pages/scripts/test-motion.cjs`（本地服务 8769，18 项；结果与截图在 `.build/`）。
- 状态机回归：`node scripts/test-window-model.cjs`（32 项，含1500步确定性随机切换）

构建会内联资源到 `index.html`，只发布此独立目录，不上传完整 Emmaus5、个人笔记、环境文件或测试备份。网站使用原本的本地状态键；首次迁移在同源浏览器另存一份旧版存档。网页保存回执支持较大的历史状态，实际容量受浏览器限制；失败会持续告警，不声称云端同步或无限历史容量。

真机键盘、安全区和原生性能仍需后续验收；浏览器模拟不等于物理手机实测。

## 窗口过渡连续性修订

- 浮窗、主窗和标签保持同一纸面底色；移动的是带原内容和滚动位置的快照，不提前替换成目标样式。
- 文字等比缩放，容器改变尺寸与裁切；到达末段才交接新布局，避免拉长文字和突然变色。
- 退到下一层的场景原地退后，不再飞向不相关的角落；支持快速连续操作清理与减少动态效果。
- `scripts/test-continuity.cjs`：浅色/深色的起点、过程、落点和减少动态效果，共 10 项。

## 窗口边界与经文衍生

- 对读采用无框连续纸面、细分隔线与短拖柄；浮窗采用柔和阴影与低对比边缘，不使用整圈绿色描边。保留同一纸面底色。
- 读经窗的笔记/研读入口仅在选中经节后可用，笔记窗不再显示这组操作。未接入研读资料的经节明确显示空态，不套用演示札记。
- 笔记默认阅读态，书卷全名/简称引用支持短按打开经文浮窗；编辑按钮切换为可编辑正文。支持章、节及节范围（定位起始节），不把裸时间如 8:28 猜成经文。
- 点击引用后保留源笔记内容与形态；不因衍生而自动最大化或收为标签；引用章号先校验，节号依据实际经文校验。笔记文本始终转义，不作为 HTML 执行。
- `scripts/test-references.cjs` 覆盖引用解析、短按衍生、编辑保存、无效引用、选经文研读和浅深色边界。

## 阅读界面视觉收敛

- 去掉对读卡片外框、圆角和有色沟槽，恢复完整阅读面。保留可拖动细分隔线，正文在窗口末端轻微渐隐，避免生硬截字。
- 浮窗缩减圆角，以低对比边缘和分层阴影区分层级；工具栏使用内缩发丝线，标题标明经文、笔记或研读。
- 悬浮标签与选经文工具条统一降低阴影强度，不修改正文密度、引用行为和窗口状态。

旧版“来源浮窗最大化 / 其他浮窗收标签”的唯一槽位规则已废止。`scripts/test-float-replacement.cjs` 现覆盖双浮窗叠放、各入口满额拦截、取消与显式继续、标签容量、拆除对读层序、真实 CDP 触摸拖动/高度调整/取消、键盘移动、切换主窗与刷新保持位置、窄屏边界，以及 v6 升级备份。

- `scripts/test-window-model.cjs`：32 项状态机与资源完整性检查（含 1500 步随机状态机）。
- `scripts/test-motion.cjs`：18 项入口、抽屉手势、缩放与布局回归。
- `scripts/test-continuity.cjs`：10 项起点、过程、落点与减少动态效果检查。

## 顶栏操作与沉浸显隐（2026-10-23）

- **窗口操作**：转为浮窗、最大化、对读、收为标签、复制为浮窗、切换浮窗、关闭；组合菜单只管拆除对读与关闭组合。
- **内容操作**：上一章/下一章、浏览前后退、为选中经文记笔记、研读、查看引用经文、编辑笔记。内容操作不再混入窗口菜单。
- 每一项菜单操作都有对应顶栏快捷按钮，保留各自的三点折叠菜单。菜单和快捷按钮由同一操作定义生成，避免漏项或能力不一致。
- 初始、新增窗口和刷新后不自动展开工具。点按窗口标题、正文或浮窗拖柄，激活并展开该窗工具；其他窗口隐藏工具。标题第一次点按仅显示工具，第二次才打开选章目录。
- 纵向滑动、滚轮或键盘阅读滚动会隐藏工具；反向滚动不会自动唤出。再次单击才显示。笔记编辑中的空格和方向键不算阅读手势。
- 去掉原先沉浸状态下右上角悬浮圆形三点按钮；窗口标题、拖柄仍可用于唤出。Enter 可激活聚焦窗口，Escape 收起工具。
- 未选中经文时，内容栏“记笔记 / 研读”禁用；上一章、下一章和浏览历史按边界禁用。保留正文中的经文引用短按衍生。
- 工具显隐与激活只属于临时界面状态，不改变双浮窗上限、窗口层级、内容或持久化格式。
- `scripts/test-window-chrome.cjs`：23 项顶栏操作归属、菜单/快捷一致性、真实触摸显隐、独占激活、笔记编辑、章节历史、引用衍生、窄屏与键盘回归；旧回归通过真实标题/拖柄点击唤出后操作。

## 宽屏对读与位置交换（2026-10-23）

- 浏览器宽度达到 760px 时展开宽屏画布（最大 1440px）；按画布实际可用宽度判断，达到 700px 则左右对读，否则上下对读。不依赖设备名称，窗口缩放、手机旋转可自动切换。
- 中间调节柄：点按交换上下 / 左右窗口，拖动沿当前分割方向调整比例。方向键微调，Enter / Space 交换。横向调节优先于右滑后台，不误开抽屉。
- 交换保持窗口身份、章节、笔记及滚动位置；比例反转让原来的大小跟随窗口移动，并沿用连续位移动效。刷新保留次序和比例，切换屏幕方向不重建窗口。
- 宽屏每个对读区域尽量保留至少 320px；缩窄时仅约束显示比例，不覆盖保存值。拆除对读以当前上方 / 左侧窗口置顶。
- 宽屏浮窗统一靠右、最大宽度 440px；新建、转换、复制和标签恢复均适用。窄屏保留原来的宽度，上下移动、高度调整与双浮窗容量规则不变。
- `scripts/test-responsive-pair.cjs`：状态机、实际触摸、键盘、宽度断点、横竖屏、持久化与浮窗限宽专项回归；截图和结果位于 `.build/responsive/`。
